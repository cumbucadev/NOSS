# Blog

O blog do NOSS é um espaço colaborativo para compartilhar conhecimento, experiências e reflexões sobre o ecossistema de Software Livre e Open Source (FLOSS).

Aqui você encontrará artigos sobre tecnologias abertas, comunidades, governança, licenciamento, segurança, carreira, sustentabilidade, diversidade, casos de sucesso e outros temas relacionados ao universo FLOSS.

Acreditamos que compartilhar conhecimento fortalece a comunidade. Por isso, este é um espaço aberto para contribuições da comunidade. Se você deseja escrever um artigo, compartilhar uma experiência ou publicar um conteúdo relevante, sua participação é muito bem-vinda.

> Quer contribuir? Abra uma Pull Request com seu artigo ou entre em contato com a comunidade do NOSS para saber mais sobre como publicar no blog.
