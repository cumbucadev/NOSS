# Eventos

Eventos são uma das principais formas de aprender, compartilhar conhecimento e fortalecer o ecossistema FLOSS (Free/Libre and Open Source Software). Conferências, encontros, hackathons, sprints, festivais e meetups aproximam pessoas da comunidade, promovem colaboração e ajudam a disseminar novas ideias, tecnologias e boas práticas.

Esta seção reúne uma lista de eventos relacionados ao universo FLOSS, organizados por ano. O objetivo é servir como um catálogo de referência para que pessoas interessadas possam acompanhar as principais conferências nacionais e internacionais, planejar sua participação e descobrir novas oportunidades de aprendizado e networking.

Cada página anual apresenta informações como:

* principais eventos nacionais;
* principais eventos internacionais;
* datas e locais de realização;
* links para os sites oficiais;
* breve descrição de cada evento.

À medida que novos eventos forem anunciados, as listas serão atualizadas para refletir o calendário de cada ano.
