# Projetos FLOSS Brasileiros

O Brasil possui uma comunidade bastante ativa no desenvolvimento de Software Livre e Open Source, responsável por criar projetos utilizados por pessoas, empresas, universidades e órgãos públicos no país e no exterior.

Esta página reúne alguns dos principais projetos FLOSS brasileiros, abrangendo diferentes áreas, como APIs, bibliotecas, sistemas de gestão, educação, ciência de dados, infraestrutura e ferramentas para desenvolvedores.

> **Quer adicionar um projeto?**
>
> Esta lista é colaborativa. Se você conhece um projeto FLOSS brasileiro que ainda não está listado, envie uma contribuição por meio do repositório do NOSS no GitHub.
