# Padrões

Esta página reúne os principais padrões citados ao longo do portal, com uma descrição breve e o link para a seção em que eles aparecem ou são relacionados.

| Padrão | Descrição | Onde é mencionado no portal |
| --- | --- | --- |
| Semantic Versioning (SemVer) | Modelo de numeração de versões que usa major, minor e patch para indicar compatibilidade e mudanças. | [Versionamento](../manutencao/versionamento.md) |
| Conventional Commits | Convenção para escrever mensagens de commit de forma padronizada, facilitando automação e leitura do histórico. | [Conventional Commits](../manutencao/conventional-commits.md) |
| Keep a Changelog | Prática de manter um arquivo de mudanças com uma estrutura clara para cada release. | [CHANGELOG.md](../manutencao/changelog-md.md) |
| All Contributors | Padrão para reconhecer e listar as pessoas que contribuíram para um projeto. | [Contribuição](../contribuicao/index.md) |
| REUSE Specification | Especificação para facilitar a identificação de licenças e metadados em arquivos de software. | [Licença de Software](../floss/licenca-de-software.md) |
| EditorConfig | Arquivo de configuração para padronizar estilo de código entre diferentes editores e ambientes. | [CONTRIBUTING.md](../manutencao/contributing-md.md) |
| SPDX License Identifiers | Identificadores padronizados para expressar licenças de software de forma clara e interoperável. | [Licença de Software](../floss/licenca-de-software.md) e [SBOM](../seguranca/sbom.md) |

Esses padrões ajudam a tornar projetos mais organizados, fáceis de manter e mais fáceis de colaborar.
