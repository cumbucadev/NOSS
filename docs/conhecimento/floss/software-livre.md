# Software Livre

**Software Livre** é um software que garante aos seus usuários a liberdade de utilizá-lo, estudá-lo, modificá-lo e redistribuí-lo. Essas liberdades são concedidas por meio de uma licença de software e constituem o princípio fundamental do movimento do Software Livre.

Ao contrário do que o nome pode sugerir, "livre" não significa necessariamente "gratuito". O termo refere-se à **liberdade** dos usuários sobre o software, e não ao seu preço. Um Software Livre pode ser distribuído gratuitamente ou comercializado.

## Como surgiu?

O movimento do Software Livre teve início na década de 1980, liderado por **Richard Stallman**.

Na época, Stallman observou que o crescente uso de software proprietário impedia que usuários compartilhassem, estudassem ou modificassem programas, dificultando a colaboração que era comum nos primeiros anos da computação.

Em resposta, ele iniciou o **Projeto GNU** em 1983, com o objetivo de criar um sistema operacional completamente livre.

Dois anos depois, em 1985, Stallman fundou a **Free Software Foundation (FSF)**, organização dedicada à promoção, proteção e defesa do Software Livre em todo o mundo.

Ao longo dos anos, a FSF passou a definir critérios para identificar quais licenças garantem efetivamente as liberdades dos usuários e promoveu a adoção do Software Livre em diferentes áreas da tecnologia.

## As quatro liberdades

Para que um software seja considerado Software Livre, ele deve garantir as quatro liberdades definidas pela Free Software Foundation:

**Liberdade 0:** executar o programa para qualquer finalidade.

**Liberdade 1:** estudar como o programa funciona e adaptá-lo às próprias necessidades.

**Liberdade 2:** redistribuir cópias do programa.

**Liberdade 3:** modificar o programa e distribuir essas modificações para outras pessoas.

Para exercer as liberdades de estudo e modificação, é indispensável que o código-fonte esteja disponível.

## Qual a importância do Software Livre?

O Software Livre promove um modelo de desenvolvimento baseado na colaboração, no compartilhamento do conhecimento e na autonomia dos usuários.

Entre seus principais benefícios estão:

* liberdade para utilizar o software sem restrições de finalidade;
* transparência sobre o funcionamento do código;
* possibilidade de auditoria independente;
* incentivo ao aprendizado e à educação;
* colaboração entre pessoas, comunidades e organizações;
* redução da dependência de fornecedores (*vendor lock-in*);
* preservação do conhecimento tecnológico;
* incentivo à inovação.

Além dos benefícios técnicos, o movimento do Software Livre defende que os usuários devem ter controle sobre a tecnologia que utilizam, evitando dependência excessiva de fabricantes ou desenvolvedores.

## Exemplos de Software Livre

Diversos softwares amplamente utilizados são considerados Software Livre, incluindo:

* Linux;
* GNU Compiler Collection (GCC);
* GNU Bash;
* GNU Emacs;
* LibreOffice;
* Firefox;
* Blender;
* PostgreSQL;
* Python;
* Git;
* VLC Media Player.

A maioria desses projetos também é considerada Open Source, pois utiliza licenças reconhecidas tanto pela Free Software Foundation quanto pela Open Source Initiative.

## O que **não** é Software Livre?

Nem todo software cujo código pode ser acessado ou utilizado gratuitamente é Software Livre.

Alguns exemplos incluem:

### Software proprietário

Softwares proprietários restringem o acesso ao código-fonte e normalmente proíbem modificações, redistribuição e outras formas de compartilhamento.

### Freeware

Um software gratuito (*freeware*) pode ser utilizado sem custo, mas isso não significa que seus usuários possuam as liberdades de estudar, modificar ou redistribuir o programa.

Gratuidade não é sinônimo de liberdade.

### Source Available

Alguns projetos disponibilizam seu código-fonte para consulta, mas impõem restrições que impedem sua livre utilização, modificação ou redistribuição.

Nesses casos, o software é considerado *Source Available*, e não Software Livre.

### Código publicado sem licença

Disponibilizar um projeto em um repositório público, como GitHub, não o torna automaticamente Software Livre.

Sem uma licença que conceda explicitamente as quatro liberdades, terceiros não possuem autorização legal para utilizar, modificar ou redistribuir o software.

## Software Livre e Open Source

Software Livre e Open Source compartilham grande parte das mesmas licenças e, na prática, descrevem a maioria dos mesmos projetos.

A principal diferença está na filosofia que orienta cada movimento. O Software Livre enfatiza a liberdade dos usuários e os aspectos éticos do compartilhamento de software, enquanto o Open Source destaca os benefícios técnicos, econômicos e colaborativos do desenvolvimento aberto.
