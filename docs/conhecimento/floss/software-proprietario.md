# Software Proprietário

**Software Proprietário** é um software cujo uso, modificação, distribuição e acesso ao código-fonte são controlados pelo detentor dos direitos autorais. Em geral, os usuários recebem apenas uma licença para utilizar o software, enquanto o código-fonte permanece fechado e protegido.

Nesse modelo, o proprietário define como o software pode ser utilizado, copiado, atualizado e distribuído, estabelecendo essas regras por meio de um contrato de licença (EULA – *End User License Agreement*) ou outro instrumento jurídico.

O Software Proprietário é o modelo adotado por grande parte da indústria de software comercial.

## Como surgiu?

Nas primeiras décadas da computação, era comum que softwares fossem compartilhados livremente entre universidades, pesquisadores e fabricantes de hardware.

A partir do final da década de 1970 e, principalmente, durante os anos 1980, o software passou a ser tratado como um produto comercial independente do hardware. Empresas começaram a restringir o acesso ao código-fonte e a comercializar licenças de uso, em vez de vender o software em si.

Esse modelo impulsionou o crescimento da indústria de software e levou ao surgimento de grandes empresas especializadas no desenvolvimento e comercialização de programas proprietários.

Como resposta a essa mudança, surgiu o movimento do **Software Livre**, liderado por Richard Stallman, defendendo que os usuários deveriam preservar a liberdade de utilizar, estudar, modificar e compartilhar o software.

## Características do Software Proprietário

Embora cada licença seja diferente, softwares proprietários normalmente apresentam características como:

* código-fonte não disponível ao público;
* restrições para modificação do software;
* proibição ou limitação da redistribuição;
* licença de uso concedida ao usuário;
* controle do desenvolvimento pelo proprietário;
* atualizações e suporte definidos pelo fabricante.

Essas características variam de acordo com a licença adotada por cada fornecedor.

## Qual a importância do Software Proprietário?

O Software Proprietário desempenha um papel importante na indústria de tecnologia e continua sendo amplamente utilizado por pessoas, empresas e governos.

Entre suas vantagens, destacam-se:

* modelo de negócios sustentável para empresas de software;
* suporte técnico oficial;
* desenvolvimento centralizado;
* integração entre produtos do mesmo fornecedor;
* responsabilidade clara sobre manutenção e evolução do software.

Por outro lado, esse modelo também pode apresentar limitações, como:

* dependência do fornecedor (*vendor lock-in*);
* menor transparência sobre o funcionamento interno do software;
* impossibilidade de corrigir ou adaptar o código sem autorização;
* limitações impostas pela licença de uso.

Essas características não tornam o Software Proprietário "melhor" ou "pior" que o Software Livre. Cada modelo atende a diferentes objetivos e necessidades.

## Exemplos de Software Proprietário

Alguns exemplos conhecidos incluem:

* Microsoft Windows;
* Microsoft Office;
* Adobe Photoshop;
* Adobe Illustrator;
* AutoCAD;
* Oracle Database;
* MATLAB;
* SAP ERP;
* Slack (cliente oficial);
* Zoom.

Muitos desses softwares oferecem versões gratuitas ou planos de teste, mas continuam sendo proprietários porque sua licença restringe o acesso ao código-fonte e sua redistribuição.

## Software Proprietário não significa software pago

É comum confundir Software Proprietário com software comercial ou pago, mas esses conceitos são diferentes.

Um software pode ser:

* **proprietário e gratuito**, como diversos aplicativos e serviços distribuídos sem custo;
* **proprietário e pago**, como muitas ferramentas profissionais;
* **livre e gratuito**, como grande parte dos projetos Open Source;
* **livre e comercial**, quando sua distribuição ocorre mediante pagamento, preservando as liberdades concedidas pela licença.

O modelo de licenciamento define as permissões concedidas aos usuários, enquanto o modelo de negócio define como o software é distribuído e monetizado.

## Software Proprietário vs. Software Livre

Software Proprietário e Software Livre representam modelos distintos de desenvolvimento e distribuição de software.

No Software Proprietário, o controle sobre o código e sua evolução permanece com o detentor dos direitos autorais.

No Software Livre, os usuários recebem liberdades para utilizar, estudar, modificar e compartilhar o software, permitindo um desenvolvimento mais aberto e colaborativo.

Ambos coexistem no ecossistema de software atual e são utilizados em diferentes contextos por indivíduos, empresas e organizações.
