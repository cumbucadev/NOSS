# Open Source vs. Software Livre

Os termos **Open Source** e **Software Livre** são frequentemente utilizados como sinônimos. Embora ambos descrevam softwares que podem ser utilizados, estudados, modificados e redistribuídos, eles representam movimentos com origens, objetivos e filosofias diferentes.

Na prática, a grande maioria dos softwares Open Source também é considerada Software Livre, e vice-versa. As principais diferenças estão na forma como cada movimento surgiu, nos objetivos que busca promover e no discurso utilizado para defender esse modelo de desenvolvimento.

## Software Livre

O movimento **Software Livre** (*Free Software*) surgiu na década de 1980, liderado por Richard Stallman e pela **Free Software Foundation (FSF)**.

Seu foco é garantir a liberdade dos usuários em relação ao software que utilizam. Para a FSF, essas liberdades são uma questão ética e social: os usuários devem ter controle sobre a tecnologia, e não depender exclusivamente de seus desenvolvedores.

Todo Software Livre deve garantir as quatro liberdades fundamentais:

* executar o programa para qualquer finalidade;
* estudar como o programa funciona;
* modificar o programa para atender às próprias necessidades;
* redistribuir cópias do programa, incluindo versões modificadas.

## Open Source

O movimento **Open Source** surgiu em 1998 com a criação da **Open Source Initiative (OSI)**.

Embora preserve praticamente as mesmas liberdades técnicas do Software Livre, seu foco é diferente. Em vez de enfatizar aspectos éticos, o Open Source destaca as vantagens práticas do desenvolvimento aberto, como:

* colaboração entre pessoas e organizações;
* maior qualidade do software;
* transparência;
* inovação acelerada;
* segurança por meio da revisão do código;
* interoperabilidade;
* redução da dependência de fornecedores (*vendor lock-in*).

A OSI define um conjunto de critérios chamado **Open Source Definition**, que estabelece os requisitos para que uma licença seja considerada Open Source.

## Principais diferenças

| Software Livre                                   | Open Source                                                        |
| ------------------------------------------------ | ------------------------------------------------------------------ |
| Ênfase na liberdade dos usuários.                | Ênfase no modelo de desenvolvimento colaborativo.                  |
| Fundamentado em princípios éticos e sociais.     | Fundamentado em benefícios técnicos, econômicos e organizacionais. |
| Promovido pela Free Software Foundation (FSF).   | Promovido pela Open Source Initiative (OSI).                       |
| Baseado nas Quatro Liberdades do Software Livre. | Baseado na Open Source Definition.                                 |

Essas diferenças são conceituais. Na prática, ambos os movimentos defendem que os usuários tenham acesso ao código-fonte e possam utilizá-lo, estudá-lo, modificá-lo e redistribuí-lo.

## Existem diferenças na prática?

Na maioria dos casos, **não**.

As licenças Open Source mais utilizadas atualmente também são consideradas licenças de Software Livre. Isso significa que um mesmo projeto pode ser descrito corretamente utilizando qualquer um dos termos.

Entre elas estão:

* MIT License;
* Apache License 2.0;
* BSD License;
* GNU GPL;
* GNU LGPL;
* GNU AGPL;
* Mozilla Public License (MPL).

Da mesma forma, diversos projetos conhecidos são simultaneamente Open Source e Software Livre, como:

* Linux;
* Git;
* Python;
* PostgreSQL;
* Kubernetes;
* Blender;
* LibreOffice;
* Firefox;
* VLC Media Player;
* Apache HTTP Server.

## Existem exceções?

Sim, mas elas são raras.

Embora a FSF e a OSI concordem sobre a grande maioria das licenças, existem alguns casos em que uma organização considera uma licença aceitável e a outra não.

Um exemplo é a **NASA Open Source Agreement (NOSA) 1.3**:

* a **OSI** aprova essa licença como Open Source;
* a **FSF** não a considera uma licença de Software Livre, por entender que algumas de suas cláusulas impõem restrições incompatíveis com as liberdades do Software Livre.

Também existem licenças destinadas a outros tipos de obras, como documentação e conteúdo, que podem não se enquadrar nas definições de Software Livre ou Open Source para software.

Esses casos são exceções e representam uma pequena parcela das licenças existentes.

## Então, qual termo devo usar?

Depende do contexto.

Utilize **Software Livre** quando quiser enfatizar os direitos e as liberdades dos usuários, especialmente em discussões sobre ética, autonomia e compartilhamento do conhecimento.

Utilize **Open Source** quando o foco estiver no desenvolvimento colaborativo, na inovação, na transparência e nos benefícios técnicos e organizacionais desse modelo.

Quando não houver necessidade de adotar uma perspectiva específica, também é comum utilizar o termo **FLOSS (Free/Libre and Open Source Software)**, que engloba ambos os movimentos.

## Resumo

As diferenças entre Open Source e Software Livre são, em sua maior parte, filosóficas e históricas, e não técnicas.

Para a grande maioria dos projetos e licenças utilizados atualmente, ambos os termos descrevem o mesmo conjunto de liberdades concedidas aos usuários. Conhecer essa distinção, no entanto, ajuda a compreender a evolução do movimento de tecnologias abertas e as diferentes perspectivas que contribuíram para o ecossistema FLOSS que conhecemos hoje.
