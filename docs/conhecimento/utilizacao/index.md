# Utilização

O ecossistema FLOSS (Free/Libre and Open Source Software) oferece milhares de projetos, ferramentas e soluções que podem ser utilizados por pessoas, empresas, organizações, instituições de ensino e governos.

No entanto, utilizar um projeto Open Source vai muito além de instalar um software. É importante compreender aspectos como licenciamento, documentação, manutenção, segurança, comunidade, suporte, governança e critérios para avaliar se uma solução é adequada para determinada necessidade.

Esta seção reúne conteúdos voltados para a **utilização de projetos e ferramentas FLOSS**, ajudando usuários a encontrar, avaliar, adotar e utilizar soluções Open Source de forma consciente e segura.

Aqui você encontrará conteúdos sobre:

* fundamentos do uso de software FLOSS;
* como encontrar projetos Open Source;
* critérios para avaliar um projeto antes da adoção;
* documentação e recursos de apoio;
* gerenciamento de dependências;
* licenciamento e obrigações de uso;
* segurança na utilização de software Open Source;
* atualização e manutenção de ferramentas;
* boas práticas para adoção em projetos pessoais e organizações;
* diretórios e catálogos de projetos FLOSS.

O objetivo desta seção é fornecer informações que ajudem pessoas e organizações a aproveitar os benefícios do software livre e de código aberto, reduzindo riscos e tomando decisões mais bem fundamentadas durante o processo de adoção.

Ao longo dos conteúdos, você encontrará desde conceitos introdutórios até guias práticos para escolher, instalar, configurar e utilizar projetos FLOSS em diferentes contextos. Também serão apresentados critérios para avaliar a maturidade, a saúde, a segurança e a sustentabilidade de um projeto antes de incorporá-lo ao seu fluxo de trabalho.

Utilizar software Open Source é também fazer parte de um ecossistema colaborativo. Quanto mais compreendemos como esses projetos são desenvolvidos e mantidos, maiores são as oportunidades de utilizá-los de forma responsável e, quando possível, contribuir para seu fortalecimento.
