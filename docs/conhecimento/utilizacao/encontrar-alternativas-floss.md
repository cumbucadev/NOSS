# Como encontrar alternativas FLOSS

Encontrar uma alternativa FLOSS (Free/Libre and Open Source Software) para um software proprietário é, muitas vezes, mais simples do que parece. Atualmente existem diversos diretórios, mecanismos de busca e comunidades dedicados a catalogar projetos Open Source para diferentes áreas, como produtividade, desenvolvimento, design, segurança, infraestrutura, inteligência artificial, educação e muito mais.

Este guia apresenta um processo simples para pesquisar e avaliar alternativas antes de adotar uma nova ferramenta.

## Por onde começar?

Antes de procurar uma alternativa, defina alguns critérios importantes:

* qual problema você deseja resolver;
* quais funcionalidades são indispensáveis;
* qual sistema operacional será utilizado;
* se a ferramenta precisa ser auto-hospedada (*self-hosted*);
* se é necessário suporte comercial;
* se há requisitos específicos de licença;
* se existem necessidades relacionadas à privacidade ou segurança.

Essas informações ajudam a reduzir o número de opções e facilitam a comparação.

## Diretórios de alternativas FLOSS

### AlternativeTo

**https://alternativeto.net**

Um dos maiores diretórios de alternativas de software. Permite pesquisar uma aplicação específica e visualizar opções semelhantes, com filtros para software Open Source, sistema operacional, licença e outros critérios.

**Ideal para:** encontrar substitutos para softwares conhecidos.

---

### AlternativeTo Open Source Filter

Dentro do próprio AlternativeTo é possível filtrar apenas softwares Open Source, facilitando bastante a pesquisa.

---

### LibreProjects

**https://libreprojects.net**

Catálogo dedicado exclusivamente a projetos livres e Open Source, organizado por categorias.

**Ideal para:** descobrir novas ferramentas FLOSS.

---

### Awesome Selfhosted

**https://awesome-selfhosted.net**

Uma das referências mais conhecidas para aplicações que podem ser hospedadas pelo próprio usuário.

Possui centenas de projetos organizados por categoria.

**Ideal para:** servidores, produtividade, colaboração e infraestrutura.

---

### Awesome Lists

**https://github.com/sindresorhus/awesome**

Coleção de centenas de listas "Awesome", cada uma focada em um tema específico.

Existem listas para:

* Python;
* JavaScript;
* IA;
* DevOps;
* Segurança;
* Kubernetes;
* Educação;
* Ciência de Dados;
* Design;
* e muito mais.

**Ideal para:** encontrar projetos recomendados pela comunidade.

---

### Open Source Alternative

**https://opensourcealternative.to**

Diretório moderno focado em alternativas Open Source para softwares populares.

Apresenta descrições curtas, categorias e links para os projetos.

---

### Privacy Guides

**https://www.privacyguides.org**

Embora tenha foco em privacidade, recomenda diversas ferramentas Open Source para comunicação, navegadores, armazenamento, VPNs, gerenciamento de senhas e outros temas.

---

### PRISM Break

**https://prism-break.org**

Projeto que recomenda alternativas Open Source voltadas para privacidade e segurança.

Muito utilizado para encontrar substitutos para serviços proprietários.

---

### Awesome Open Source

**https://awesomeopensource.com**

Permite pesquisar milhares de projetos Open Source organizados por linguagem, categoria e tecnologia.

---

### FLOSS Directory (FSF)

**https://directory.fsf.org**

Diretório mantido pela Free Software Foundation com foco em Software Livre.

Embora menor que outros diretórios modernos, continua sendo uma boa referência para projetos que seguem estritamente os princípios do Software Livre.

---

### GitHub Topics

**https://github.com/topics**

O GitHub permite navegar por projetos utilizando *topics* como:

* static-site-generator
* note-taking
* password-manager
* terminal
* markdown
* documentation
* devops

É uma excelente forma de descobrir projetos populares.

## Como avaliar uma alternativa?

Encontrar uma ferramenta é apenas o primeiro passo. Antes de adotá-la, vale a pena avaliar alguns aspectos.

### Projeto ativo

Verifique:

* data do último commit;
* frequência de releases;
* atividade recente.

### Comunidade

Observe:

* quantidade de contribuidores;
* tempo de resposta às Issues;
* participação da comunidade.

### Documentação

Uma boa documentação costuma indicar maior maturidade do projeto.

Procure por:

* README;
* documentação oficial;
* tutoriais;
* exemplos;
* guias de instalação.

### Licença

Verifique qual licença Open Source é utilizada e se ela é compatível com o seu uso.

### Segurança

Considere se o projeto possui:

* SECURITY.md;
* releases frequentes;
* correções de vulnerabilidades;
* SBOM (quando aplicável);
* políticas de segurança.

### Saúde do projeto

Alguns indicadores importantes incluem:

* número de mantenedores;
* distribuição das contribuições;
* frequência de atualizações;
* adoção por outras organizações.

## Comparando alternativas

Ao comparar diferentes ferramentas, considere critérios como:

| Critério               | Perguntas                                          |
| ---------------------- | -------------------------------------------------- |
| Funcionalidades        | Atende às necessidades do projeto?                 |
| Licença                | É compatível com o uso pretendido?                 |
| Comunidade             | O projeto é ativo?                                 |
| Documentação           | É fácil aprender a utilizar?                       |
| Segurança              | O projeto responde rapidamente a vulnerabilidades? |
| Sustentabilidade       | Há sinais de continuidade a longo prazo?           |
| Integrações            | Funciona com outras ferramentas utilizadas?        |
| Facilidade de migração | É possível importar dados da solução atual?        |

## Não existe uma alternativa perfeita

Nem sempre uma ferramenta FLOSS terá exatamente as mesmas funcionalidades de uma solução proprietária.

Em muitos casos, será necessário considerar fatores como:

* facilidade de uso;
* recursos disponíveis;
* maturidade do projeto;
* tamanho da comunidade;
* necessidade de suporte comercial;
* possibilidade de customização.

A melhor escolha depende do contexto e das necessidades de cada pessoa ou organização.

## Contribua com o ecossistema

Ao encontrar uma boa alternativa FLOSS, considere também apoiar o projeto.

Isso pode ser feito de diversas formas:

* reportando bugs;
* melhorando a documentação;
* respondendo dúvidas da comunidade;
* contribuindo com código;
* traduzindo conteúdos;
* fazendo doações ou tornando-se patrocinador.

Quanto mais pessoas utilizam e apoiam projetos FLOSS, mais forte e sustentável se torna todo o ecossistema.
