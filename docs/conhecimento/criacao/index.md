# Criação de um Projeto

Criar um projeto FLOSS (Free/Libre and Open Source Software) envolve muito mais do que criar um repositório e publicar o código. As decisões tomadas nos primeiros dias do projeto influenciam sua organização, facilidade de adoção e potencial para receber contribuições no futuro.

Esta seção reúne conteúdos voltados para a **criação de novos projetos Open Source**, desde a concepção da ideia até a publicação da primeira versão.

Aqui você encontrará conteúdos sobre:

* fundamentos para criação de projetos FLOSS;
* planejamento e definição do escopo;
* organização da estrutura do repositório;
* documentação inicial;
* escolha da licença;
* ferramentas recomendadas para novos projetos;
* checklists e boas práticas para iniciar um projeto.

O objetivo desta seção é fornecer um guia para ajudar pessoas e organizações a criarem projetos Open Source bem estruturados desde o início, adotando práticas que facilitem seu crescimento e sua colaboração futura.
