# Comunidades Brasileiras de Open Source

O ecossistema brasileiro de Open Source é formado por centenas de comunidades que promovem conhecimento, colaboração, eventos, desenvolvimento de projetos e apoio a pessoas que desejam contribuir com tecnologias abertas.

Cada comunidade possui seu próprio foco: algumas são voltadas para linguagens de programação, outras para tecnologias específicas, projetos, diversidade e inclusão, sistemas operacionais, ciência aberta ou cultura livre.

Abaixo está uma lista de algumas das principais comunidades brasileiras relacionadas ao Open Source.

> **Quer sugerir uma comunidade?** Abra uma contribuição no repositório do projeto para que possamos manter esta lista sempre atualizada.

## Como escolher uma comunidade?

Se você está começando, não se preocupe em encontrar a comunidade "perfeita". O mais importante é participar, conhecer pessoas e começar a contribuir.

Uma boa comunidade costuma oferecer:

- ambiente acolhedor e respeitoso;
- canais ativos para dúvidas e discussões;
- documentação clara para novos contribuidores;
- eventos, encontros ou grupos de estudo;
- oportunidades de colaboração em projetos Open Source.
