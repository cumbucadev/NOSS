# Organizações

O ecossistema de Software Livre e Open Source (FLOSS) é sustentado por organizações que promovem tecnologias abertas, oferecem infraestrutura, apoiam comunidades, definem padrões, financiam projetos e incentivam a colaboração em todo o mundo.

Nesta página, você encontrará algumas das principais organizações nacionais e internacionais relacionadas ao FLOSS, acompanhadas de uma breve descrição de sua atuação e links para seus sites oficiais.

> Esta lista não é oficial nem completa. Se você conhece uma organização que contribui significativamente para o ecossistema de FLOSS, contribua com uma Pull Request.

## Fundações

Organizações responsáveis pela governança, sustentabilidade e evolução de grandes projetos e ecossistemas Open Source.

| Organização | Descrição | Site |
|-------------|-----------|------|
| Open Source Initiative (OSI) | Define e promove o conceito de Open Source e aprova licenças Open Source. | <https://opensource.org> |
| Free Software Foundation (FSF) | Promove e defende o Software Livre. | <https://www.fsf.org> |
| Linux Foundation | Apoia centenas de projetos Open Source, incluindo Linux e Kubernetes. | <https://www.linuxfoundation.org> |
| Apache Software Foundation | Responsável pela governança de projetos como Apache HTTP Server, Maven e Kafka. | <https://apache.org> |
| Eclipse Foundation | Apoia projetos relacionados a desenvolvimento de software, IoT e cloud. | <https://eclipse.org> |
| Python Software Foundation (PSF) | Responsável pelo suporte e desenvolvimento do ecossistema Python. | <https://python.org/psf> |
| Mozilla Foundation | Promove uma internet aberta por meio de projetos e iniciativas Open Source. | <https://foundation.mozilla.org> |
| Rust Foundation | Apoia o desenvolvimento e a sustentabilidade da linguagem Rust. | <https://rustfoundation.org> |
| GNOME Foundation | Responsável pela governança do projeto GNOME. | <https://foundation.gnome.org> |
| KDE e.V. | Organização que apoia a comunidade KDE. | <https://ev.kde.org> |

## Organizações Internacionais

Entidades que apoiam projetos, comunidades e iniciativas Open Source em escala global.

| Organização | Descrição | Site |
|-------------|-----------|------|
| OpenJS Foundation | Apoia projetos do ecossistema JavaScript. | <https://openjsf.org> |
| Cloud Native Computing Foundation (CNCF) | Hospeda projetos cloud native como Kubernetes, Prometheus e Envoy. | <https://cncf.io> |
| OpenInfra Foundation | Apoia projetos de infraestrutura aberta, como OpenStack. | <https://openinfra.org> |
| Software Freedom Conservancy | Oferece suporte jurídico, administrativo e financeiro para projetos FLOSS. | <https://sfconservancy.org> |
| Software in the Public Interest (SPI) | Dá suporte legal e financeiro a projetos como Debian e PostgreSQL. | <https://spi-inc.org> |
| NumFOCUS | Apoia projetos científicos Open Source como NumPy, SciPy, Pandas e Jupyter. | <https://numfocus.org> |
