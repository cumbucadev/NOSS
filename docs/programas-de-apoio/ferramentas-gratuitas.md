# Programas de Ferramentas Gratuitas

Projetos FLOSS (Free/Libre and Open Source Software) dependem de diversas ferramentas para desenvolver software, gerenciar contribuições, monitorar aplicações, produzir documentação e colaborar com suas comunidades.

No entanto, muitas dessas ferramentas possuem planos pagos que podem representar um custo elevado para projetos comunitários.

Os **programas de ferramentas gratuitas** oferecem acesso gratuito ou com desconto a softwares e serviços comerciais para projetos Open Source elegíveis. Dessa forma, ajudam comunidades a utilizar ferramentas profissionais sem comprometer seu orçamento.

Embora não forneçam recursos financeiros diretamente, esses programas reduzem custos operacionais e permitem que projetos concentrem seus esforços no desenvolvimento do software.

## O que são programas de ferramentas gratuitas?

São iniciativas criadas por empresas de software para disponibilizar gratuitamente seus produtos a projetos Open Source.

Esses programas podem incluir acesso a:

* IDEs;
* ferramentas de colaboração;
* plataformas de monitoramento;
* gerenciamento de incidentes;
* gerenciamento de projetos;
* produtividade;
* segurança;
* observabilidade;
* design;
* comunicação.

Os critérios de elegibilidade variam conforme cada empresa.

## Como funcionam?

Normalmente, o processo segue etapas semelhantes.

1. O projeto solicita participação.
2. A empresa avalia se o projeto atende aos requisitos.
3. Caso aprovado, o projeto recebe acesso gratuito ou com desconto às ferramentas.
4. O benefício pode ser renovado periodicamente.

Em muitos casos, é necessário que o projeto:

* utilize uma licença Open Source reconhecida;
* possua repositório público;
* esteja ativo;
* não tenha fins exclusivamente comerciais.

## Benefícios

Esses programas oferecem diversas vantagens.

Entre elas:

* redução de custos;
* acesso a ferramentas profissionais;
* aumento da produtividade;
* melhoria da colaboração;
* fortalecimento da qualidade do software;
* suporte técnico em alguns casos;
* integração com outras plataformas.

## Principais categorias de ferramentas

Os programas podem disponibilizar diferentes tipos de software.

### Desenvolvimento

Ferramentas utilizadas durante o desenvolvimento.

Exemplos:

* IDEs;
* depuradores;
* ferramentas de análise de código.

---

### Colaboração

Ferramentas para comunicação e gestão de projetos.

Exemplos:

* gerenciamento de tarefas;
* documentação;
* comunicação entre equipes.

---

### Monitoramento e observabilidade

Ferramentas para acompanhar aplicações em produção.

Exemplos:

* monitoramento;
* métricas;
* logs;
* rastreamento distribuído;
* gerenciamento de incidentes.

---

### Segurança

Ferramentas voltadas para:

* análise de vulnerabilidades;
* gerenciamento de segredos;
* segurança de aplicações;
* análise de dependências.

---

### Design e produtividade

Ferramentas utilizadas para documentação, design e colaboração visual.

## Exemplos de programas ativos

### JetBrains Open Source License

A JetBrains oferece licenças gratuitas para diversos de seus produtos a projetos Open Source elegíveis.

Entre eles:

* IntelliJ IDEA Ultimate;
* PyCharm Professional;
* WebStorm;
* GoLand;
* Rider;
* CLion;
* PhpStorm.

As licenças destinam-se às pessoas mantenedoras e contribuidoras dos projetos aprovados.

---

### Docker Sponsored Open Source

O Docker oferece benefícios para projetos Open Source por meio do programa **Docker Sponsored Open Source**.

Dependendo da elegibilidade, o programa inclui recursos adicionais para gerenciamento de imagens e colaboração no Docker Hub.

---

### GitKraken Open Source

O GitKraken disponibiliza licenças gratuitas para projetos Open Source qualificados.

As licenças incluem acesso às funcionalidades premium da plataforma de gerenciamento Git.

---

### 1Password for Open Source

Projetos Open Source elegíveis podem receber acesso gratuito ao 1Password Teams.

Isso permite armazenar e compartilhar credenciais de forma segura entre pessoas mantenedoras.

---

### Sentry for Open Source

O Sentry oferece benefícios para determinados projetos Open Source, facilitando o monitoramento de erros e falhas em aplicações.

---

### Datadog Open Source Program

A Datadog disponibiliza acesso gratuito a parte de sua plataforma para projetos Open Source elegíveis.

Os benefícios podem incluir monitoramento de infraestrutura, aplicações e observabilidade.

---

### Figma for Open Source

O Figma oferece acesso gratuito ao plano Professional para organizações Open Source qualificadas, facilitando a criação colaborativa de interfaces, protótipos e materiais de design.

## Como escolher um programa?

Antes de solicitar participação, vale considerar:

* quais ferramentas realmente são necessárias;
* critérios de elegibilidade;
* quantidade de licenças oferecidas;
* duração do benefício;
* facilidade de integração com o fluxo de trabalho do projeto;
* políticas de renovação.

Também é importante avaliar se a comunidade do projeto conseguirá manter essas ferramentas caso o benefício seja encerrado.

## Programas de ferramentas e sustentabilidade

Esses programas contribuem diretamente para a sustentabilidade técnica e organizacional de projetos FLOSS.

Ao reduzir custos com ferramentas profissionais, permitem que recursos financeiros sejam direcionados para outras áreas, como infraestrutura, segurança, documentação ou remuneração de pessoas mantenedoras.

Além disso, ajudam pequenos projetos a utilizar ferramentas normalmente acessíveis apenas a grandes organizações.
